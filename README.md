# 추억의 오락실 (flashgames)

방과 후 컴퓨터실에서 하던 웹 미니게임들의 느낌을 살려, **모든 게임을 새로 만들어** 한곳에 모은 사이트입니다.
다른 게임의 파일이나 그림을 가져오지 않고 규칙·그림·음악을 직접 만들었습니다.

| 게임 | 장르 | 내용 |
| --- | --- | --- |
| 🍙 주먹밥 용사전 | RPG | 도트 그림 마을·필드 탐험과 칸 위 전략 전투. 8장 이야기 중 제1장. 게으른 무술 소년과 덜렁이 마법사가 사라진 종을 찾아 산적굴로 |
| 🦖 햄스터 다이노 파이트 | 격투 | 햄스터 8마리가 커맨드 기술로 싸우다, 게이지가 차면 각자의 공룡(티라노·트리케라톱스·스테고사우루스·안킬로사우루스·프테라노돈·브라키오사우루스·랩터·스피노사우루스) 특징이 돋아나며 변신. 스토리는 7마리와 싸운 뒤 마지막에 숨겨진 보스, 클리어하면 보스를 고를 수 있음. 컴퓨터 대전·2인 대전 |
| 🌰 도토리 미로 | 미로 추격 | 밤의 숲 미로에서 다람쥐가 도토리를 모으고, 저마다 다르게 쫓아오는 고양이 넷을 피함. 황금 도토리를 먹으면 고양이를 잡을 수 있음. 단계가 오를수록 빨라짐 |

### 주먹밥 용사전 ~여덟 개의 종~

도트 그림 RPG. 마을 사람과 이야기하며 돌아다니다가, 적을 만나면 8×5 칸 위에서 움직이며 싸우는 전략 전투로 넘어갑니다.

- **이야기**: 하늘에서 내려온 여덟 개의 종이 「밤의 왕」을 재우고 있다. 그 종을 훔치는 「검은 깃털」을 쫓아 게으른 무술 소년 **하루**와 시험에 일곱 번 떨어진 자칭 천재 마법사 **미르**가 길을 떠난다. 전체 8장 중 **제1장 「솔방울 마을의 게으름뱅이」**를 플레이할 수 있습니다 (마을 → 바람 언덕 → 도토리 숲 → 곰발톱 산적굴 → 보스 → 종탑).
- **전투**: 빠른 순서대로 차례가 오고, 파란 칸으로 움직인 뒤 공격·기술·도구·대기·도망. 미르의 주문은 가끔 엉뚱하게 실수합니다. 회심의 일격·미스, 경험치·레벨업, 도구 줍기.
- **그 밖에**: 여관(회복·기록), 잡화점, 보물상자, 팻말, 전멸하면 돈 절반을 잃고 마을에서 깨어남, 메뉴에서 상태·도구·기록.
- **그림**: 사람·몬스터는 16×16 칸에 부품(머리 모양·모자·옷·소품)을 칠한 뒤 자동으로 외곽선과 명암을 넣어 만듭니다. 타일도 코드로 찍은 도트.
- **조작**: 방향키 이동 · `Z`/`Enter` 확인·말 걸기 · `X`/`Esc` 메뉴·취소 · 휴대폰은 A·B 버튼.

### 햄스터 다이노 파이트

버튼은 **약펀치 · 강펀치 · 약킥 · 강킥 · 기** 다섯 개입니다.

| 입력 (방향키를 하나씩 차례로, 바라보는 쪽 기준) | 기술 |
| --- | --- |
| `↓ → + 펀치` | 기술 1 (캐릭터마다 다름: 해바라기씨 탄, 뿔 돌격, 물대포…) |
| `→ ↓ → + 펀치` | 기술 2 (대공기, 시작할 때 무적) |
| `↓ ← + 킥` | 기술 3 (돌진·회전·받아치기·급강하…) |
| `↓ → ↓ → + 펀치` | 변신 중 초필살기 (게이지 절반 사용) |
| `기` 누르고 있기 | 기 모으기: 게이지가 차지만 그동안 무방비 |
| 게이지 가득일 때 `기` | 공룡 변신 (변신하는 동안 무적, 터질 때 가까운 상대를 밀어냄. 강해지고 게이지가 서서히 줄어듦) |

대각선(두 키 동시)은 누르지 않아도 됩니다. 대각선으로 굴려도 인정합니다.

**이어 치기**: 공격이 맞거나 막히면 다음 공격으로 끊어 이어집니다. `약펀치 → 약킥 → 강펀치 → 강킥 → 기술 (→ 변신 중이면 초필살기)` 순서로 약한 쪽에서 센 쪽으로. 이어 맞을수록 피해는 조금씩 줄어듭니다. 앉아서 누르면 약펀치는 앉아 찌르기, 강펀치는 올려치기, 약킥은 다리 걸기, 강킥은 쓸어 차기.

**게이지**: 때리면 맞을 때보다 두 배쯤 더 찹니다. 막아도 조금 찹니다.

상대 반대쪽을 누르면 막기, 아래+뒤는 앉아 막기 (다리 공격은 앉아서 막아야 함). 휴대폰은 기술 버튼으로 바로 쓸 수 있습니다.

| 햄스터 | 변신 | 특징 |
| --- | --- | --- |
| 렉스 | 티라노사우루스 | 고른 능력치, 큰 턱 |
| 트리코 | 트리케라톱스 | 돌격 중 밀리지 않는 뿔 돌격, 프릴 방패 |
| 스테고 | 스테고사우루스 | 긴 리치, 가시 꼬리 회전 |
| 안키 | 안킬로사우루스 | 단단한 등껍질, 곤봉 꼬리와 받아치기 |
| 프테 | 프테라노돈 | 가장 높은 점프, 변신하면 활공, 급강하 |
| 브라키 | 브라키오사우루스 | 가장 긴 리치, 짓밟기 |
| 랩터 | 벨로키랍토르 | 가장 빠른 연속 공격 |
| 스피노 | 스피노사우루스 | 물을 쓰는 원거리형 |
| ??? | ??? | 스토리를 깨면 등장 |

## 실행

```bash
docker compose up -d --build
# → http://localhost:8082
```

전적과 최고 기록은 브라우저에 저장됩니다.

## 조작

- **햄스터 다이노 파이트** 1P `WASD` 이동 · `U` 약펀치 `I` 강펀치 · `J` 약킥 `K` 강킥 · `L` 기 / 2P 방향키 · 숫자패드 `4` `5` 펀치 · `1` `2` 킥 · `3` 기 (숫자패드가 없으면 `7` `8` `9` `0` `-`) / 컴퓨터와 할 때는 방향키 + `1`~`5`도 됨
- **도토리 미로** 방향키 또는 `WASD`
- 휴대폰: 격투는 화면 아래 버튼(기술 버튼 포함), 미로는 화면을 밀어서
- `Esc` 일시정지

## 음악·효과음

음원 파일 없이 게임 안에서 직접 작곡·합성합니다 (`src/core/music.ts` 작곡, `src/core/audio.ts` Web Audio 연주).
8비트 오락실 느낌의 네모파·삼각파·잡음으로 연주하고, 정해 둔 화음 진행 위에서 마디마다 멜로디를 새로 만들되 앞 두 마디를 되풀이해 곡처럼 들리게 합니다.

| 곡 | 어디서 |
| --- | --- |
| 동전 넣고 기다리기 | 첫 화면 |
| 옥상 위의 결투 | 햄스터 다이노 파이트 |
| 어둠의 성 | 햄스터 다이노 파이트 최종 보스전 |
| 한밤의 도토리 줍기 | 도토리 미로 |

## 새 게임 추가하기

1. `src/games/<id>/` 에 `engine.ts`(규칙, 화면과 분리), `render.ts`(캔버스 그리기), `<이름>Game.tsx`(화면)를 만든다.
2. `src/games/registry.ts` 에 한 줄 추가하고, 필요하면 `src/core/music.ts` 에 곡을 추가한다.
3. `src/App.tsx` 에 경로를 잇고, `tests/` 에 규칙 테스트를 넣는다.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 규칙 테스트 (격투·컴퓨터 상대·미로·음악)
npm run build   # 타입 검사 + 빌드
```

GitHub Actions가 푸시할 때마다 테스트·타입 검사·빌드·Docker 이미지 확인을 합니다.

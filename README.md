### 깨비 도감 ~금빛 호리병~

한빛 군도를 여행하며 깨비를 잡고 키우는 수집 RPG. 설계 메모는 `docs/kkaebi-design.md`.

- **깨비 195종**: 3단 진화 64계열 + 숨은 깨비 3종(금빛봉황·은빛해룡·달빛구미). 속성 18종과 상성, HP·공격·방어·특공·특방·스피드와 개체값, 레벨 100 제한, 계열마다 다른 진화 레벨.
- **기술 142개**: 물리·특수·변화, 화상·독·마비·잠듦·얼음·혼란·풀죽음, 능력 단계, 흡수·반동·연속·선제·급소·회복. 기술 부적 30종과 비전 부적 6종(베어내기·빛내기·장사의힘·파도타기·하늘날기·폭포오르기).
- **여행**: 마을·길·숲·동굴·바닷길 30곳 남짓, 체육관 8곳, 흑연단 아지트, 라이벌, 사천왕과 깨비 왕. 인장을 모으면 비전 기술로 작은 나무·어두운 굴·큰 돌·바다·폭포를 지나간다. 턱 뛰어넘기, 달리기, 트레이너 시야.
- **밤낮**: 컴퓨터 시계로 아침·낮·밤. 밤에만 나오는 깨비, 밤엔 화면이 어두워진다.
- **잡기·키우기**: 호리병(4종)으로 포획(흔들림 3번), 경험치 나눔, 레벨업·기술 배우기(4개 넘으면 잊을 기술 선택), 진화 연출(취소 가능), 쉼터·보관함·잡화점·부적 가게, 도감(본 깨비·잡은 깨비).
- **도트**: 깨비는 64×64 칸 만화풍 도트. 64계열 + 숨은 깨비 3종을 계열마다 따로 디자인했다(`src/games/kkaebi/forms.ts`). 예: 새싹 아기사슴 → 덩굴 사슴 → 꽃 핀 고목 뿔의 숲의 왕, 꼬리 불씨 쥐 → 불꽃 줄무늬 담비 → 두 발로 선 불꽃 범 무사, 물방울 개구리 → 두꺼비 → 등에서 폭포를 뿜는 거대 두꺼비. 진화하면 몸의 형태·자세·특징이 바뀐다. 부위별 5단 명암·색 외곽선·큰 눈(홍채·반짝임)은 자동으로 넣고, 숨쉬기·눈 깜빡임 그림이 있다.
- **연출**: 풀숲에서 깨비를 만나면 주인공 머리 위에 느낌표 → 두 번 번쩍 → 소용돌이로 화면이 덮이고(트레이너는 줄무늬, 전설은 빛), 전투 화면이 열리며 발판이 미끄러져 들어온다. 야생 깨비는 그림자로 들어와 번쩍 색을 찾고, 호리병에서 나올 땐 빛 조각과 함께 톡 튀어나온다. 진화는 빛줄기 속에서 하얀 몸이 옛 모습과 새 모습을 점점 빨리 오가다 터진다. 풀숲을 걸으면 발목이 풀에 가려지고 잎이 흩날린다.
- **도구·유대**: 솔내마을에서 대나무 낚싯대(물가를 보고 쓰면 물속 깨비)와, 인장 1개 뒤 두바퀴(자전거, 걷기의 두 배 넘게 빠름)를 받는다. 깨비마다 유대(♥)가 있어 함께 걷고·싸우고·레벨이 오르면 깊어지고, 높으면 한 전투에 한 번 트레이너가 몸을 던져 쓰러질 공격을 막아 준다. 처음 고른 세 마리의 마지막 모습은 유대가 아주 높으면(레벨 40+) 숨은 「유대 진화」(금빛 기운, 능력 15%↑). 마을·사냥터에 들어가면 한 줄 소개가 뜬다.
- **글씨·배속**: 글씨는 도트 글꼴 갈무리(SIL OFL, npm `galmuri`)를 원래 크기의 배수로 찍는다. 전투는 C(또는 Tab)로 ×1·×2·×3 배속, 전투 중 Shift를 누르고 있으면 ×3. 휴대폰은 ▶▶ 버튼.
- **개발자용 정리표**: `docs/kkaebi-data.xlsx` (진화표 · 능력치 · 배우는 기술 · 기술 목록 · 부적 호환 · 상성표).
- **조작**: 방향키 이동 · Shift(또는 X를 누른 채) 달리기 · `Z`/`Enter` 확인 · `X`/`Esc` 메뉴·취소. 휴대폰은 A·B 버튼.

### 주먹밥 용사전 ~여덟 개의 종~

도트 그림 RPG. 마을 사람과 이야기하며 돌아다니다가, 적을 만나면 8×5 칸 위에서 움직이며 싸우는 전략 전투로 넘어갑니다.

- **이야기**: 하늘에서 내려온 여덟 개의 종이 「밤의 왕」을 재우고 있다. 그 종을 훔치는 「검은 깃털」을 쫓아 게으른 무술 소년 **하루**와 시험에 일곱 번 떨어진 자칭 천재 마법사 **미르**가 길을 떠난다. 전체 8장 중 **제1장 「솔방울 마을의 게으름뱅이」**를 플레이할 수 있습니다 (마을 → 바람 언덕 → 도토리 숲 → 곰발톱 산적굴 → 보스 → 종탑).
- **전투**: 빠른 순서대로 차례가 오고, 파란 칸으로 움직인 뒤 공격·기술·도구·방어·대기·도망. 미르의 주문은 가끔 엉뚱하게 실수합니다. 회심의 일격·미스, 경험치·레벨업, 도구 줍기.
- **장비**: 무기·옷·장신구 세 칸. 가게·상자·보스에게서 얻고, 「바람 머리띠」(질풍 돌려차기)·「별빛 지팡이」(별똥별 우수수)·「거북 등껍질」(등껍질 철벽)·「곰발톱 장갑」(곰발톱 연타)처럼 기술이 붙은 장비도 있습니다.
- **방어**: 다음 차례까지 받는 피해 절반. 기술마다 불꽃·얼음 기둥·별똥별·바람 고리·땅울림 같은 이펙트가 다릅니다.
- **대화**: 말하는 사람의 도트 얼굴이 대화창에 나오고, 가까이 가면 머리 위에 이름이 뜹니다.
- **그 밖에**: 여관(회복·기록), 잡화점, 보물상자, 팻말, 전멸하면 돈 절반을 잃고 마을에서 깨어남, 메뉴에서 상태·도구·기록.
- **그림**: 사람·몬스터는 16×16 칸에 부품(머리 모양·모자·옷·소품)을 칠한 뒤 자동으로 외곽선과 명암을 넣어 만듭니다. 타일도 코드로 찍은 도트.
- **조작**: 방향키 이동 · `Z`/`Enter` 확인·말 걸기 · `X`/`Esc` 메뉴·취소 · 휴대폰은 A·B 버튼.

### 햄스터 다이노 파이트

버튼은 **약펀치 · 강펀치 · 약킥 · 강킥 · 기** 다섯 개입니다.

| 입력 (방향키를 하나씩 차례로, 바라보는 쪽 기준) | 기술 |
| --- | --- |
| `↓ → + 펀치` | 기술 1 (캐릭터마다 다름: 해바라기씨 탄, 뿔 돌격, 물대포…) |
| `→ ↓ → + 펀치` | 기술 2 (대공기, 시작할 때 무적) |
| `↓ ← + 킥` | 기술 3 (돌진·회전·받아치기·급강하…) |
| `↓ → ↓ → + 펀치` | 변신 중 초필살기 (게이지 절반 사용) |
| `기` 누르고 있기 | 기 모으기: 게이지가 차지만 그동안 무방비 |
| 게이지 가득일 때 `기` | 공룡 변신 (변신하는 동안 무적, 터질 때 가까운 상대를 밀어냄. 강해지고 게이지가 서서히 줄어듦) |

대각선(두 키 동시)은 누르지 않아도 됩니다. 대각선으로 굴려도 인정합니다.

**이어 치기**: 공격이 맞거나 막히면 다음 공격으로 끊어 이어집니다. `약펀치 → 약킥 → 강펀치 → 강킥 → 기술 (→ 변신 중이면 초필살기)` 순서로 약한 쪽에서 센 쪽으로. 이어 맞을수록 피해는 조금씩 줄어듭니다. 앉아서 누르면 약펀치는 앉아 찌르기, 강펀치는 올려치기, 약킥은 다리 걸기, 강킥은 쓸어 차기.

**게이지**: 때리면 맞을 때보다 두 배쯤 더 찹니다. 막아도 조금 찹니다.

상대 반대쪽을 누르면 막기, 아래+뒤는 앉아 막기 (다리 공격은 앉아서 막아야 함). 휴대폰은 기술 버튼으로 바로 쓸 수 있습니다.

| 햄스터 | 변신 | 특징 |
| --- | --- | --- |
| 렉스 | 티라노사우루스 | 고른 능력치, 큰 턱 |
| 트리코 | 트리케라톱스 | 돌격 중 밀리지 않는 뿔 돌격, 프릴 방패 |
| 스테고 | 스테고사우루스 | 긴 리치, 가시 꼬리 회전 |
| 안키 | 안킬로사우루스 | 단단한 등껍질, 곤봉 꼬리와 받아치기 |
| 프테 | 프테라노돈 | 가장 높은 점프, 변신하면 활공, 급강하 |
| 브라키 | 브라키오사우루스 | 가장 긴 리치, 짓밟기 |
| 랩터 | 벨로키랍토르 | 가장 빠른 연속 공격 |
| 스피노 | 스피노사우루스 | 물을 쓰는 원거리형 |
| ??? | ??? | 스토리를 깨면 등장 |

## 실행

```bash
docker compose up -d --build
# → http://localhost:8082
```

전적과 최고 기록은 브라우저에 저장됩니다.

## 조작

- **햄스터 다이노 파이트** 1P `WASD` 이동 · `U` 약펀치 `I` 강펀치 · `J` 약킥 `K` 강킥 · `L` 기 / 2P 방향키 · 숫자패드 `4` `5` 펀치 · `1` `2` 킥 · `3` 기 (숫자패드가 없으면 `7` `8` `9` `0` `-`) / 컴퓨터와 할 때는 방향키 + `1`~`5`도 됨
- **도토리 미로** 방향키 또는 `WASD`
- 휴대폰: 격투는 화면 아래 버튼(기술 버튼 포함), 미로는 화면을 밀어서
- `Esc` 일시정지

## 음악·효과음

음원 파일 없이 게임 안에서 직접 작곡·합성합니다 (`src/core/music.ts` 작곡, `src/core/audio.ts` Web Audio 연주).
8비트 오락실 느낌의 네모파·삼각파·잡음으로 연주하고, 정해 둔 화음 진행 위에서 마디마다 멜로디를 새로 만들되 앞 두 마디를 되풀이해 곡처럼 들리게 합니다.

| 곡 | 어디서 |
| --- | --- |
| 동전 넣고 기다리기 | 첫 화면 |
| 옥상 위의 결투 | 햄스터 다이노 파이트 |
| 어둠의 성 | 햄스터 다이노 파이트 최종 보스전 |
| 한밤의 도토리 줍기 | 도토리 미로 |

## 새 게임 추가하기

1. `src/games/<id>/` 에 `engine.ts`(규칙, 화면과 분리), `render.ts`(캔버스 그리기), `<이름>Game.tsx`(화면)를 만든다.
2. `src/games/registry.ts` 에 한 줄 추가하고, 필요하면 `src/core/music.ts` 에 곡을 추가한다.
3. `src/App.tsx` 에 경로를 잇고, `tests/` 에 규칙 테스트를 넣는다.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 규칙 테스트 (격투·컴퓨터 상대·미로·음악)
npm run build   # 타입 검사 + 빌드
```

GitHub Actions가 푸시할 때마다 테스트·타입 검사·빌드·Docker 이미지 확인을 합니다.

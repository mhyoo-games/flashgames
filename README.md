# 추억의 오락실 (flashgames)

방과 후 컴퓨터실에서 하던 웹 미니게임들의 느낌을 살려, **모든 게임을 새로 만들어** 한곳에 모은 사이트입니다.
다른 게임의 파일이나 그림을 가져오지 않고 규칙·그림·음악을 직접 만들었습니다.

| 게임 | 장르 | 내용 |
| --- | --- | --- |
| 🥋 막대 결투 | 격투 | 옥상 위 졸라맨 1:1 대결. 3단 콤보, 발차기, 막기, 점프 공격, 게이지를 모아 쏘는 기공파. 컴퓨터(쉬움·보통·어려움) 또는 한 키보드 2인 대전. 3판 2선승 |
| 🌰 도토리 미로 | 미로 추격 | 밤의 숲 미로에서 다람쥐가 도토리를 모으고, 저마다 다르게 쫓아오는 고양이 넷을 피함. 황금 도토리를 먹으면 고양이를 잡을 수 있음. 단계가 오를수록 빨라짐 |

## 실행

```bash
docker compose up -d --build
# → http://localhost:8082
```

전적과 최고 기록은 브라우저에 저장됩니다.

## 조작

- **막대 결투** 1P `A` `D` 이동 · `W` 점프 · `S` 막기 · `J` 주먹 · `K` 발차기 · `L` 기공파 / 2P 방향키 · `1` `2` `3`
- **도토리 미로** 방향키 또는 `WASD`
- 휴대폰: 격투는 화면 아래 버튼, 미로는 화면을 밀어서
- `Esc` 일시정지

## 음악·효과음

음원 파일 없이 게임 안에서 직접 작곡·합성합니다 (`src/core/music.ts` 작곡, `src/core/audio.ts` Web Audio 연주).
8비트 오락실 느낌의 네모파·삼각파·잡음으로 연주하고, 정해 둔 화음 진행 위에서 마디마다 멜로디를 새로 만들되 앞 두 마디를 되풀이해 곡처럼 들리게 합니다.

| 곡 | 어디서 |
| --- | --- |
| 동전 넣고 기다리기 | 첫 화면 |
| 옥상 위의 결투 | 막대 결투 |
| 한밤의 도토리 줍기 | 도토리 미로 |

## 새 게임 추가하기

1. `src/games/<id>/` 에 `engine.ts`(규칙, 화면과 분리), `render.ts`(캔버스 그리기), `<이름>Game.tsx`(화면)를 만든다.
2. `src/games/registry.ts` 에 한 줄 추가하고, 필요하면 `src/core/music.ts` 에 곡을 추가한다.
3. `src/App.tsx` 에 경로를 잇고, `tests/` 에 규칙 테스트를 넣는다.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 규칙 테스트 (격투·컴퓨터 상대·미로·음악)
npm run build   # 타입 검사 + 빌드
```

GitHub Actions가 푸시할 때마다 테스트·타입 검사·빌드·Docker 이미지 확인을 합니다.
